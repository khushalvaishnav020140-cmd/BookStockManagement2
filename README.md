# Book Stock Management System

A web-based library management application built using Java.

## Features
- Dashboard
- Add and edit books
- Search books
- Manage book stock
- Issue and return books

## Technologies Used
- Java
- JSP and Servlets
- MySQL
- JDBC
- Apache Tomcat 10.1
- Eclipse IDE

## Database
Database Name: book_stock_db
